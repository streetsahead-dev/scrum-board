Scrum Board

Click anywhere to add a note. Drag by the dotted strip. Turn off snapping to place notes freely.

Sync across computers

Your board saves to a private file in your GitHub account. Do this once on each computer.

  1. Create a GitHub token. The "gist" box is already checked. Set expiration to "No expiration," then click Generate token.
  2. Copy the token and paste it here.
